# Index Grup Tanıtım Sitesi

Index Grup'un altı grup şirketini (Index, Despec, Datagate, Netex, Teklos, HB Bilişim) tanıtan, HTML ve CSS ile sıfırdan geliştirilmiş çok sayfalı bir kurumsal web sitesi projesi.

## 🔗 Canlı Site

[https://elisardibek.github.io/index-grup-site/](https://elisardibek.github.io/index-grup-site/)

## 📋 Proje Hakkında

Bu proje, Doğuş Üniversitesi Yazılım Mühendisliği bölümü HTML5/CSS öğrenim sürecinin bir parçası olarak geliştirilmiştir. Ana sayfa ve altı şirket sayfasının yanı sıra, siteyi daha kapsamlı hale getirmek amacıyla ek sayfalar da eklenmiştir.

## 🗂️ Sayfa Yapısı

| Sayfa | Açıklama |
|---|---|
| `index.html` | Ana sayfa — grup tanıtımı, marka logoları, öne çıkanlar |
| `index-firma.html` | Index şirketi |
| `despec.html` | Despec şirketi |
| `datagate.html` | Datagate şirketi |
| `netex.html` | Netex şirketi |
| `teklos.html` | Teklos şirketi |
| `hb-bilisim.html` | HB Bilişim şirketi |
| `hakkimizda.html` | Kurumsal bilgiler, misyon, vizyon, tarihçe |
| `sss.html` | Sıkça sorulan sorular |
| `kariyer.html` | Açık pozisyonlar ve başvuru |
| `haberler.html` | Haberler listesi |
| `haber-1.html` – `haber-6.html` | Haber detay sayfaları |
| `iletisim.html` | İletişim formu (Formspree entegrasyonlu) |

## 🛠️ Kullanılan Teknolojiler

- **HTML5** — semantic etiketler (`nav`, `section`, `footer`, `article`, `details`)
- **CSS3** — Flexbox, Grid, medya sorguları (responsive tasarım), animasyonlar
- **JavaScript** — mobil navigasyon menüsü, URL parametresi ile form ön doldurma
- **Formspree.io** — sunucu tarafı kod yazmadan iletişim formu işleme
- **Git & GitHub** — versiyon kontrolü
- **GitHub Pages** — statik site barındırma

## 📱 Responsive Tasarım

Site aşağıdaki ekran genişliklerinde test edilmiş ve düzgün çalışacak şekilde tasarlanmıştır:
- 360px (mobil)
- 768px (tablet)
- 1280px (masaüstü)

## 🖼️ Görseller

Sitede kullanılan tüm görseller [Pexels](https://www.pexels.com) üzerinden ücretsiz, ticari kullanıma uygun lisansla temin edilmiştir. Her görsele erişilebilirlik amacıyla açıklayıcı `alt` metni eklenmiştir.
